# Homebrew Codex Tap

Homebrew tap for [codex-provider-switcher](https://github.com/RomaCredit/codex-provider-switcher).

## Install

```bash
brew tap RomaCredit/codex
brew install codex-provider-switcher
cps --version
```

The formula installs the latest tagged release and uses Homebrew's isolated
Python virtual environment support. The tap does not collect telemetry.
